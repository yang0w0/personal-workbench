# 便携式 Windows 客户端

## 运行方式

Tauri 将 `app/index.html` 内嵌进 `个人工作台.exe`。发布后的客户端不使用固定盘符、用户名或安装目录：每次启动都会从客户端所在文件夹向上寻找同级 `data` 文件夹。

最终可携带目录如下：

```text
个人工作台/
├─ 个人工作台.exe
├─ data/
├─ app/                 # 保留浏览器版 HTML，便于直接打开
├─ start-server.cmd      # 浏览器版需要，本客户端不需要
└─ 其他项目文件
```

因此移动整个 `个人工作台` 文件夹到其他盘符或其他电脑后，客户端仍会操作该文件夹中的 `data`。不要只移动 `.exe` 而遗漏 `data`。

## 构建前置条件

构建 `.exe` 的电脑需要：

1. Node.js 20+。
2. Rust（`rustup` 安装的稳定版 MSVC 工具链）。
3. Microsoft C++ Build Tools，包含 Desktop development with C++ 工作负载。

然后双击根目录的 `build-client.cmd`。它会下载 Tauri 的构建依赖、编译客户端，并将生成的 `个人工作台.exe` 放到项目根目录。

## 使用与兼容性

- 日常使用双击 `个人工作台.exe`；无需启动本机 Node 服务。
- 浏览器版双击 `app/index.html`，仍需启动 `start-server.cmd`。
- Tauri 依赖 Microsoft Edge WebView2。较新的 Windows 通常已具备；若目标电脑缺少它，需要安装微软的 WebView2 Runtime。
- 客户端和浏览器版共用 `data/catalog.json` 与中文分类目录，因此同一时刻只应使用其中一个界面修改数据，避免同时写入索引文件。

## ⚠️ 两个必须知道的行为

**1. 界面是编译进 exe 的。**
`app/index.html` 在构建时被内嵌进 `个人工作台.exe`。所以改了前端（或 `desktop/` 里的代码）之后：

| | 生效方式 |
| --- | --- |
| 浏览器版 | 刷新浏览器即可 |
| 桌面版 | **必须重新构建**（双击 `build-client.cmd`），增量约 1.5 分钟 |

构建前必须确认 `个人工作台.exe` 没有在运行，否则最后一步复制会失败。

**2. 桌面版目前是浏览器版能力的子集。**

| 能力 | 浏览器版 | 桌面版 |
| --- | --- | --- |
| 脚本 / 网址 | ✅ | ✅ |
| 应用 / 文档分类 | ✅ | ❌ |
| 自定义分类（增删改） | ✅ | ❌ |
| 扫描开始菜单与桌面的快捷方式 | ✅ | ❌ |
| 编辑时修改网址目标 | ✅ | ❌ |
| 上传自定义图标 | ✅ | ✅ |

需要这些能力时请用浏览器版。完整差异清单和字段差异见 [tauri-ipc.md](interfaces/tauri-ipc.md)。

> ⚠️ 另外：**桌面版执行写入操作会清掉 `catalog.json` 里的分类注册表**（自建分类会从界面消失）。在修复前建议用浏览器版改数据。详见 [DATA_FORMAT.md](DATA_FORMAT.md#数据完整性提醒)。

## 开发这个客户端

客户端相关的改动请先读 [接口文档 · 桌面客户端](interfaces/tauri-ipc.md)（含 10 个 IPC 命令、配置契约与已知偏差），以及 [接口总纲](INTERFACES.md) 的模块边界规则。**不要用固定盘符或安装目录**，客户端必须能整个文件夹搬走就用。
