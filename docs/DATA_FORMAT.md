# 本地数据格式

## 原始文件

- `data/脚本/`：脚本源文件。可从页面新建，也可手动复制到这里。
- `data/网址/`：Windows `.url` 文件。服务读取其中的 `URL=` 字段。
- `data/待整理/`：暂未分类的文件。扫描后出现在页面的待处理列表。
- `data/密码库/`：仅用于未来的加密密码库文件，当前必须保持为空。

## 索引文件

服务首次运行时创建 `data/catalog.json`。它记录每个条目的名称、说明、标签、来源文件标识和状态；原始脚本内容仍保存在 `data/脚本/`。

索引不是浏览器缓存，而是本地磁盘上的数据文件。请勿手工编辑正在被服务写入的文件；修改前先关闭本地服务并备份 `data`。

## 分类规则

| 目录 | 类型 | 页面行为 |
| --- | --- | --- |
| `脚本` | 小脚本 | 显示为脚本条目；未登记的文件标记为待补充。 |
| `网址` | `.url` 网址快捷方式 | 解析网址并标记为待补充。 |
| `待整理` | 任意待分类文件 | 提醒用户选择分类、名称与标签；完成后文件会移入对应目录。 |
| `密码库` | 加密密码库（未来） | 当前不扫描、不读取。 |
