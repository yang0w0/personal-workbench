# 本地数据格式

> 这份文档是写给**使用者**的：你的数据放在哪、长什么样、怎么改才安全。
> 开发者和 AI agent 请改读 [接口文档 · 数据契约](interfaces/data-catalog.md)，那份才是权威契约。

## 原始文件

| 目录 | 放什么 |
| --- | --- |
| `data/脚本/` | 脚本源文件。可从页面新建，也可手动复制进来 |
| `data/网址/` | Windows `.url` 快捷方式。服务读取其中的 `URL=` 字段 |
| `data/应用/` | 从开始菜单或桌面收进来的 `.lnk` 快捷方式（会复制一份进来，保留启动参数与图标） |
| `data/文档/` | 用默认程序打开的文档或文件夹 |
| `data/待整理/` | 暂未分类的文件。扫描后出现在页面的「待补充」列表 |
| `data/密码库/` | 预留，仅用于未来的加密密码库文件，**当前必须保持为空** |
| `data/备份/` | 预留，加密备份 |

自建分类会自动对应到 `data/` 下的一个同名文件夹。

## 索引文件

服务首次运行时创建 `data/catalog.json`，它记录两部分内容：

1. **分类注册表**：每个分类的名称、对应文件夹、类型（脚本/网址/应用/文档）、图标符号、显示顺序。
2. **条目列表**：每个条目的名称、说明、标签、来源文件、图标、状态、打开次数、排序位置。

原始脚本内容保存在 `data/脚本/` 里的真实文件，索引只记录路径与元信息。

**索引不是浏览器缓存，而是本地磁盘上的数据文件。** 请通过界面修改它：

- 不要手工编辑 `catalog.json`（它可能正被服务写入，且格式变化会导致数据丢失）；
- 修改前先关闭本地服务并备份整个 `data/` 文件夹。

## 分类与状态

| 类型 | 页面行为 |
| --- | --- |
| 脚本 | 显示为图标；点击运行；未登记的文件标记为待补充 |
| 网址 | 解析 `.url` 里的网址；点击用默认浏览器打开 |
| 应用 | 点击启动对应程序（用复制进来的 `.lnk`，保留参数与工作目录） |
| 文档 | 点击用系统默认程序打开 |
| 待整理 | 收件箱：补充分类、名称与标签后，文件会被移入对应目录 |

条目有三个状态：

| 状态 | 含义 |
| --- | --- |
| 待补充 | 扫描发现但信息未补全，显示在「待补充」列表 |
| 已完成 | 信息齐全，显示为可点击的图标 |
| 已忽略 | 主动忽略，不再出现在待补充列表，文件仍留在磁盘上 |

## 排序与图标

- **排序**：在「脚本」「网址」网格里拖拽图标即可调整顺序，顺序保存在索引的 `order` 字段中。
  「常用」网格是按打开次数自动排的，不参与手动排序。
- **图标**：可以在新增/编辑条目时上传图片，会自动压缩后保存在索引里（不产生额外文件）。
  没有图标时显示占位符号（脚本 `▣`、网址 `↗`）。

## 什么时候需要「扫描并同步」

- 你手动往 `data/` 里放了文件、或删掉了某文件；
- 你在资源管理器里改了文件名。

| 操作 | 结果 |
| --- | --- |
| 新增未登记的文件 | 列为「待补充」，填完信息后变成图标 |
| 外部删除了索引里登记的文件 | 再次扫描时该条目从索引中移除 |
| 在界面里删除条目 | 索引和对应的磁盘文件一起删除 |

## ⚠️ 数据完整性提醒

**桌面客户端执行任何写入操作（新建、编辑、删除、排序、扫描）后，`catalog.json` 里的分类注册表会被清掉**，自建分类会从界面消失（磁盘上的文件夹还在）。这是已知问题，尚未修复。

在修复之前：**优先使用浏览器版修改数据**；确实要用桌面版时，先复制一份 `data/` 备份。技术原因见 [tauri-ipc.md 的已知偏差](interfaces/tauri-ipc.md#已知偏差)。
